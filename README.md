# extract-text

飞书多维表格字段捷径项目。  
作用是读取一条记录中的附件字段，调用阿里云 DashScope / 百炼的 `paraformer-v1` 录音文件识别接口，把音频或视频里的中文语音转成文本，并把结果写回多维表格。

## 功能说明

- 输入：一个飞书多维表格附件字段
- 识别语言：固定中文
- 输出：纯文本转写结果
- 认证方式：飞书字段捷径授权面板填写阿里百炼 API Key
- 运行方式：飞书字段捷径 FaaS

## 前置条件

使用前需要准备：

1. 飞书多维表格，可创建附件字段
2. 阿里云 DashScope / 百炼账号
3. 已开通语音识别相关服务
4. 可用的阿里百炼 API Key

API Key 官方获取文档：

- <https://help.aliyun.com/zh/model-studio/get-api-key>

当前项目调用的阿里云接口文档：

- <https://help.aliyun.com/zh/model-studio/developer-reference/paraformer-recorded-speech-recognition-restful-api>

## 本地联调

### 1. 配置本地测试 API Key

编辑项目根目录下的 `config.json`：

```json
{
  "authorizations": [
    "你的阿里百炼 API Key"
  ]
}
```

说明：

- 这个文件只用于本地 `npm run dev` 联调
- 它不会被正式打包进发布产物
- `.gitignore` 已忽略这个文件，避免误提交

### 2. 启动飞书字段捷径本地服务

```bash
npm start
```

成功后会在本地启动 `8080` 端口，供飞书“字段捷径调试助手”连接。

### 3. 运行本地测试脚本

```bash
npm run dev
```

## 在飞书多维表格中配置

### 1. 准备附件字段

在飞书多维表格中新增一个“附件”字段，并上传待转写的音频或视频文件。

建议先用一条记录做验证，再批量使用。

### 2. 打开字段捷径调试助手

在飞书右侧边栏中打开“字段捷径调试助手”，确保它能连接你本地 `8080` 服务。

### 3. 新建字段捷径列

在多维表格中新建一列，类型选择“字段捷径”，然后在调试助手中选择当前项目。

### 4. 填写授权

配置面板里会看到：

- `阿里百炼 API Key`

在这里填入你的阿里百炼 API Key。

### 5. 绑定输入字段

配置面板里还会看到：

- `音频/视频附件`

把它绑定到你前面创建的附件字段。

### 6. 保存并执行

保存后，用“调试字段”或“更新”触发执行。  
执行成功后，字段捷径列会直接写入中文转写文本。

本项目根目录下的 `config.json` 只在本地调试时使用。

## 当前实现说明

当前版本的字段捷径行为如下：

- 固定识别中文，不提供语种切换
- 返回值是纯文本字段
- 只处理当前记录的第一个附件
- 依赖飞书附件字段运行时提供的 `tmp_url`
- 也支持公网可访问的视频或音频文件 URL

## 常见问题

### 1. 为什么飞书里执行失败？

优先检查：

- API Key 是否填写正确
- 阿里云百炼账号是否欠费或无额度
- 飞书附件字段是否真的有文件
- 文件 URL 是否能被阿里云服务访问

### 2. 为什么本地 `npm run dev` 可以，飞书里不行？

常见原因：

- 飞书侧未填写 API Key
- 绑定错了附件字段
- 上传的是不支持或异常的文件

### 3. 为什么结果为空？

常见原因：

- 文件里没有可识别的人声
- 音质太差
- 语音不是中文
- 媒体文件虽然可访问，但音轨异常
